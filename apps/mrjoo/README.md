# مستر جو v3 — تشغيل في ~١٥ دقيقة

**المعاينة بدون أي إعداد:** افتح `index.html` عبر أي سيرفر محلي (`npx serve .`) — هتشتغل في وضع تجريبي (فيد، ألعاب، تداول تجريبي، هدايا محلية).

## التشغيل الحقيقي (كله مجاني للبداية)
1. **Supabase**: أنشئ مشروع ← SQL Editor ← الصق `schema.sql` ونفّذه. من Authentication → Providers → Email عطّل *Confirm email*.
2. **Vercel**: ارفع المجلد (GitHub أو `vercel deploy`) وضع المتغيرات من `.env.example` في Settings → Environment Variables.
3. افتح `/admin` وادخل بـ `ADMIN_KEY` — منها تؤكد الشحن وتحوّل السحب وتسجّل إيراد الإعلانات.
4. **البث المباشر**: حساب LiveKit Cloud مجاني ← ضع `LIVEKIT_URL/API_KEY/API_SECRET`. بدونها شاشة البث تشتغل معاينة فقط.
5. **الإعلانات**: بعد قبول AdSense ضع `ADSENSE_CLIENT` و`ADSENSE_FEED_SLOT`.

## الفلوس تمشي إزاي
- المستخدم بيحوّل على **رقم فودافون كاش بتاعك** (`VODAFONE_CASH_NUMBER`) ويكتب رقم العملية ← تأكده من `/admin` ← عملات مدفوعة.
- هدية بعملات **مدفوعة** ← ٥٠٪ فلوس قابلة للسحب للمبدع (`CREATOR_SHARE`)، والباقي ليك.
- هدية بعملات **مجانية** (ألعاب/مشاهدة/تحديات) ← نقاط للمبدع تدخل **صندوق المبدعين الأسبوعي** المتمول من إيراد الإعلانات الحقيقي (تسجّله من `/admin`). كده مفيش وعود فلوس من فراغ.
- السحب: المبدع يطلب على رقم 010 بتاعه ← الرصيد يتخصم فوراً ← أنت تحوّل يدوي من فودافون كاش ← تضغط «تم».
- التداول: **تجريبي بفلوس افتراضية** (جوايز أسبوعية من الصندوق للتلاتة الأوائل).

## حدود لازم تعرفها
- AdSense والشبكات الإعلانية **لا تدفع على فودافون كاش**؛ بتدفع لحساب بنكي/Payoneer/غيره. فودافون كاش هنا للشحن والسحب بين المستخدمين وبينك.
- الإعلانات بتدفع حسب الزيارات الحقيقية؛ مفيش "ربح سريع مضمون". لا تحفّز المستخدمين على الضغط على الإعلانات (مخالف لسياسات AdSense).
- الألعاب والمشاهدة عليها حدود يومية وتحقق من السيرفر، لكنها مش مضادة للبوتات بالكامل؛ راجع السحوبات الكبيرة قبل التحويل.
- فلوس مستخدمين حقيقية = التزامات قانونية/ضريبية؛ استشر محاسب/محامي قبل الإطلاق العام.

# Google-joo · منصة Jo1

منصة فيديو قصير عمودي (تيك توك-like) فيها بث مباشر، هدايا، محفظة، ألعاب، ولوحة أدمن.
هذا المستودع يجمع كل أجزاء المشروع في مكان واحد بعد أن كانت في ملفات zip متفرقة.

## الأجزاء

| المجلد | ما هو | أين يُنشر |
|---|---|---|
| `apps/platform` | المنصة نفسها (Next.js) | Vercel — Root Directory = `apps/platform` |
| `apps/control` | **التيرمنال الوحيد** للتحكم الكامل (الأدمن، الحظر، المحفظة، الألوان، النشر) | Vercel — مشروع منفصل، Root = `apps/control` |
| `services/worker` | تحويل الفيديو إلى HLS (360p + 720p) | Render / Railway / Fly — Dockerfile |
| `supabase/` | قاعدة البيانات: الجداول، الدوال، السياسات، الهدايا | Supabase SQL Editor بالترتيب الرقمي (01 إلى 07) |
| `docs/` | التركيب، المتغيرات، الهيكل، الأمان، سجل التغييرات | — |

## قواعد لا تُكسر

- **لا تضع أي مفتاح `SERVICE_ROLE` ولا `VERCEL_TOKEN` ولا `*_SECRET` في الواجهة أو في Git.** هي فقط في إعدادات Vercel/Render.
- ملفات `.env` مستثناة من Git (انظر `.gitignore`). الملف الموجود هو `.env.example` فقط.
- شغّل SQL بالترتيب الرقمي فقط: `01` ثم `02` ... ثم `07`. كل ملف آمن لو تكرر تشغيله.
- التحكم بالمنصة كلها من `apps/control` فقط. لا توجد لوحة أدمن أخرى تحمل مفاتيح تحكم.
- Worker واحد فقط في كل مرة.

## التحقق

ملف CI في `.github/workflows/ci.yml` يفحص الأنواع (`typecheck`) والبناء (`build`) لكل تطبيق، وصياغة الـ worker. كل تغيير يمر منه قبل النشر.

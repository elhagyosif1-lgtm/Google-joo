# مساحة «اترك أثراً»

هذه الإضافة تعرض داخل Jo1 دليلاً لمبادرات خيرية مقترحة، وتبقي تسجيل الدخول ضمن Supabase Auth الحالي. لا تنشئ محفظة جديدة ولا تعالج تبرعات أو تحويلات مالية.

## التفعيل

1. خذ نسخة احتياطية من قاعدة Supabase، ثم راجع وشغّل `supabase/09_impact_hub.sql` بعد ملفات المخطط والأمان الحالية.
2. افحص أسماء الجهات ووصفها واعتمادها محلياً. صفوف البذور تبدأ `is_active = false` حفاظاً على عدم نشرها قبل المراجعة.
3. بعد التحقق فقط، فعّل الجهات المراد عرضها من SQL Editor الموثوق، مثلاً:

```sql
update public.impact_charities
set is_active = true
where id = '<uuid-reviewed-by-admin>';
```

4. انشر مشروع `apps/platform` كالمعتاد. الرابط `/impact`، ويوجد اختصار «اترك أثراً» عائم داخل المنصة.

## حدود الأمان

- مستخدمو المنصة المصادق عليهم يمكنهم قراءة السجلات النشطة فقط؛ لا توجد صلاحيات كتابة من المتصفح.
- لا تضع كلمات مرور أو مفاتيح خدمة أو أسرار دف�� في ملفات الواجهة أو Git.
- لا يوجد دفع/تبرع داخل التطبيق في هذه الإضافة. لا تعرض أرقام محافظ أو وعوداً بنسبة توزيع قبل بناء تكامل مالي موثق، ومراجعته قانونياً وأمنياً.
- بيانات الجهات أمثلة أولية من المواد الواردة، وليست اعتماداً أو تزكية من Jo1. تحقق من التسجيل والبيانات الرسمية قبل تفعيل العرض.
